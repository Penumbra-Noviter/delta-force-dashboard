# Y-04：侧边栏账号区（下拉框 + 新建账号 + 命名对话框）

- **Blocked by**: Y-03（需先有当前账号状态与解析）
- **Status**: ready-for-agent

## What to build

用户视角：侧边栏顶部出现「账号」区——当前账号下拉框 +「新建账号」按钮；点新建弹出命名对话框，输入非法名（空 / 重名 / 含禁用字符 / 首尾空格或点）被拒绝并给出可读提示；合法名创建后立即出现在下拉列表，但当前账号不变（留在原账号，需手动切换）；记账页标题栏显示当前账号名。

端到端验证：点击新建 → 输入合法名 → 确定 → 下拉列表出现新账号、当前选中不变；输入非法名 → 拒绝提示、无目录产生。

## 文件范围

- 修改 `app/sidebar.py`（顶部账号区：下拉框 + 新建按钮 + 信号）
- 修改 `app/main_window.py`（命名对话框接线、标题更新、账号列表刷新）
- 修改 `app/ui_text.py`（如需新增 emoji，走 EMOJI 单一来源）
- 修改 `tests/test_ui_smoke.py`（创建流程集成用例，含拒绝路径）

## 高不确定实现点

**【布局可行性】侧边栏固定 130px 宽度**（U-04，现有测试断言 `sidebar.width() == 130`）——下拉框 + 按钮在 130px 内排布紧张：需评估「扩宽侧边栏（连带 QSS 与宽度断言同步改）」或「压缩控件布局」。建议实现前先做小 spike 验证布局可行性，再定案。

## 验收标准

- [ ] 侧边栏顶部账号区就位：下拉框列出全部账号且当前账号选中 +「新建账号」按钮
- [ ] 命名对话框：非法名拒绝并给出可读提示（空名 / 重名 / 含 `\ / : * ? " < > |` / 首尾空格或点），拒绝时不产生目录
- [ ] 新建成功 → 下拉列表立即出现新账号；当前选中不变（留在当前账号，决策 6）
- [ ] 新账号从空数据开始（H5）
- [ ] 记账页标题栏显示当前账号名（随账号区状态同步）
- [ ] 新增 emoji（如需）走 EMOJI 扩展；UI 不直接拼账号路径（Y-03 的 AST 断言持续生效）
- [ ] 集成用例：创建成功路径 / 各拒绝路径 / 下拉列表内容 / 标题更新；覆盖率维持 ≥ 90%
