# ADR-0004：侧边栏导航 + 多页面系统

## 决策背景

收益计算器原为单页应用（输入面板 → 表格 → 图表）。需要新增两个 Delta Force 辅助功能（制造利润排行、卡战备推荐），用户要求通过左侧边栏切换页面。

## 可选方案

### 方案 A：QStackedWidget + 侧边栏

App 主窗口改为水平布局：左侧固定侧边栏 + 右侧 QStackedWidget。现有仪表盘作为 Page 0，新功能作为 Page 1/2。

| 优势 | 代价 |
|------|------|
| 原生 Qt 方案，零额外依赖 | 需将现有 `_build_ui` 的布局内聚为独立容器 Page |
| 页面切换不销毁状态，切回即恢复 | 侧边栏 `QListWidget` 样式需自行定制 |
| QStackedWidget 索引切换 O(1) | |

### 方案 B：QTabWidget + 标签页

用 QTabWidget 替代侧边栏，Tab 位于顶部。

| 优势 | 代价 |
|------|------|
| Qt 内置，开箱即用 | 用户指定左侧边栏，非顶部 Tab |
| 自带样式 | 顶部 Tab 与现有标题栏冲突 |
| 已有 Tab 切换动效 | 现有按钮无处安放 |

### 方案 C：QDialog 弹窗式新窗口

新功能以独立弹窗打开，不改造主窗口布局。

| 优势 | 代价 |
|------|------|
| 不改现有布局，零侵入 | 用户要求侧边栏切换，而非弹窗 |
| 可独立关闭/打开 | 多窗口管理复杂，与现有单实例冲突 |
| | 信息孤岛，数据不联动 |

## 最终选择

✅ **方案 A：QStackedWidget + 侧边栏**

## 理由

- 用户明确要求「侧边栏切换」
- 用户指定左侧边栏 + 底部放现有按钮
- QStackedWidget 与现有 WidgetRegistry 注册机制兼容
- 方案 B 与现有布局冲突，方案 C 不满足需求

## 影响

### 正面
- 新增功能不影响现有记账页面的布局逻辑
- 制造利润和卡战备页面可独立开发/测试
- 侧边栏可继续扩展（后续加更多导航项）

### 代价
- 需要将现有 `_build_ui` 中的仪表盘内容（标题栏 + 日期 + 注册 widgets）提取为 `DashboardPage`
- 现有按钮（主题/置顶/导出CSV）从标题栏移至侧边栏底部
- `MainWindow` 的 `_build_ui` 需要重写布局逻辑

### 文件变化

```
app/
├── main_window.py      # 改：水平布局（sidebar + stacked widget）
├── sidebar.py          # 新：左侧导航栏 + 底部按钮
├── kkrb_client.py      # 新：kkrb.net API 客户端
├── crafting_page.py    # 新：制造利润页面
├── gear_page.py        # 新：卡战备推荐页面
├── __init__.py         # 改：导出新模块
```

### kkrb.net API 说明

两个数据端点已验证可用（Playwright 实测）：

| 端点 | 方法 | 返回 |
|------|------|------|
| `POST https://www.kkrb.net/getOVData` | POST | 制造产物数据（4 台位推荐 + 利润 + 售价） |
| `POST https://www.kkrb.net/getCPVData` | POST | 卡战备方案数据（多档位 + 多方案 + 装备明细） |

需要 `x-csrf-token` 请求头，从首页 HTML 中提取或首次请求后获取。

### 领域词汇更新

| 术语 | 含义 |
|------|------|
| 制造台位 | 特勤处中的 4 个制造设施（技术中心/工作台/制药台/防具台） |
| 卡战备 | 以最低成本凑满指定地图准入战备价值的装备搭配方案 |
| 战备值 | 装备提供的战斗力数值，不同地图有不同准入门槛 |
